# AI resources

We built an open-source AI skill for Logos node operators. It lets you install, update, and check the status of a Logos Blockchain node with natural-language commands from Claude Code, GitHub Copilot, Gemini CLI, OpenAI Codex, opencode, and OpenClaw. Use the GitHub skill files in your agent setup, or install the package directly. Once installed, you can handle fresh setups, breaking upgrades, and quick sync checks from the same agent workflow.

```bash
npx @citizenweb3/ai-integrations logos-node
```

```bash
curl -fsSL https://raw.githubusercontent.com/citizenweb3/ai-integrations/logos-node/install.sh | bash
```

```bash
/logos-node install
/logos-node update
/logos-node status
```
